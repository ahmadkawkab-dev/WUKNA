# Wukna agent guidance

Read `.agents/AGENTS.md` for the detailed repository guidance when it is present.

Navigation ordering is a standing product rule:

- Place Library immediately after Boards whenever Library is available.
- Keep Notifications last in the sidebar's primary destinations and mobile More.
- Show storage directly below Notifications as a separate workspace utility,
  outside the Library navigation group. Keep it available across workspace pages
  whenever Library is enabled, including mobile More and collapsed navigation.
- Preserve this ordering when adding or moving destinations. Account identity
  controls and board lists remain separate from the primary destination list.

Code files belong to Documents and use a code viewer. Do not create a separate
Code Snippets destination, category, or storage workflow.
